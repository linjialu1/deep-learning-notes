## 1. 文本预处理

### 1.1 文本预处理及其作用

文本语料在输送给模型前一般需要一系列的预处理工作，才能符合模型输入的要求：
- 将文本转化成模型需要的张量
- 规范张量的尺寸
- 科学的文本预处理还将有效指导模型超参数的选择，提升模型的评估指标

### 1.2 文本预处理的主要环节

- 文本处理的基本方法（分词、词性标注、命名实体识别）
- 文本张量表示方法（one-hot、Word2vec、Word Embedding）
- 文本语料的数据分析（标签分布、句子长度、词频统计）
- 文本特征处理（n-gram特征、文本长度规范）
- 数据增强方法（回译数据增强法）

> 实际生产中最常使用的两种语言是中文和英文，预处理内容都针对这两种语言讲解。

## 2. 文本处理的基本方法

### 2.1 分词

分词就是将连续的字序列按照一定的规范重新组合成词序列的过程。

- 英文单词之间有空格作为自然分界符，中文没有形式上的分界符，需要分词
- 词是语言语义理解的最小单元，是NLP高阶任务的基础

**jieba 分词工具：**

三种分词模式：
- **精确模式**：试图将句子最精确地切开，适合文本分析（默认）
- **全模式**：把句子中所有可以成词的词语都扫描出来，速度快，但不能消除歧义
- **搜索引擎模式**：在精确模式基础上，对长词再次切分，提高召回率，适合搜索引擎

其他功能：
- 支持中文繁体分词
- 支持用户自定义词典（添加领域专有名词，提升识别准确率）

### 2.2 命名实体识别（NER）

- **命名实体**：人名、地名、机构名等专有名词（如：周杰伦、北京、阿里巴巴）
- **命名实体识别（Named Entity Recognition）**：识别出一段文本中可能存在的命名实体

**作用：**
同词汇一样，命名实体也是人类理解文本的基础单元，是NLP高阶任务的重要基础环节。

### 2.3 词性标注（POS）

- **词性**：语言中对词的分类方法，以语法特征为主要依据，常见的有名词、动词、形容词等
- **词性标注（Part-Of-Speech tagging）**：标注出一段文本中每个词汇的词性

**作用：**
词性标注以分词为基础，是对文本语言的另一个角度的理解，也是NLP高阶任务的重要基础环节。

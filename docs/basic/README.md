## 1. 激活函数（Activation Function）

目前学习了四种激活函数：**sigmoid、tanh、relu、softmax**

### 1.1 Sigmoid

- 将任意输入映射到 **(0, 1)** 之间
- 当输入值大致在 `<-6` 或 `>6` 时，输出趋近饱和，丢失部分信息
- 网络 5 层之内容易出现**梯度消失**现象
- 一般用于**二分类的输出层**

### 1.2 Tanh

- 将输入映射到 **(-1, 1)** 之间
- 图像以 0 为中心，在 0 点对称
- 当输入大概 `<-3` 或 `>3` 时，将被映射为 -1 或 1
- 导数值范围 **(0, 1)**，输入过大或过小时导数近似 0

**与 Sigmoid 对比：**
- ✅ 以 0 为中心，梯度比 Sigmoid 大，收敛速度更快，迭代次数更少
- ❌ 两侧导数同样为 0，依然会造成梯度消失

### 1.3 ReLU

- 将小于 0 的值映射为 0，大于 0 的值保持不变
- 更重视正信号，忽略负信号
- 运算简单，提高模型训练效率

**神经元死亡问题：**
- 当 `x < 0` 时，ReLU 的导数 = 0
- 训练推进过程中，部分输入会落入小于 0 的区域，对应的权重无法更新，导致"神经元死亡"

**改进版本：PReLU**
- 可以接受负的信号，用来解决神经元死亡问题

### 1.4 Softmax

- 用于**多分类**过程
- 是二分类函数 Sigmoid 在多分类上的推广
- 目的是将多分类结果以**概率**形式展现
- 输出结果选取多分类中概率最大的那个

## 2. 参数初始化

### 2.1 常见初始化方法（7 种）

全 0 初始化、全 1 初始化、随机均匀分布初始化、正态分布初始化、Kaiming 初始化、Xavier 初始化、固定值初始化

### 2.2 初始化的目的

1. **打破对称性**
2. **防止梯度消失或梯度爆炸**
3. **提高收敛速度**

> 💡 激活函数使用最多的是 ReLU，Kaiming 初始化专门针对 ReLU 函数做了优化设计。

## 4. 损失函数

> 在深度学习中，损失函数是用来**衡量模型参数质量的函数**，衡量方式是比较网络输出（预测值）和真实输出（真实值）的差异。

### 4.1 多分类任务损失函数

大白话：最小化正确类别所对应的预测概率的对数负数。

公式：`L = -∑ y log(S(f(x)))`

### 4.2 二分类任务损失函数

公式中不包含 Sigmoid 函数，使用时需要手动调用 Sigmoid 激活函数。

公式：`L = -y log(x) - (1-y) log(x)`

- `y` 为真实值
- `x` 为样本的预测概率
- `L` 用来衡量真实值 y 与预测值 x 之间的损失结果

### 4.3 回归任务损失函数

#### MAE 损失函数（L1 Loss）

- 公式：误差绝对值之和 / 样本总数
- 缺点：在 0 点不可导，数据容易变得稀疏

#### MSE 损失函数

- 公式：误差平方值和 / 样本总数
- 缺点：如果差值过大，可能存在梯度爆炸的情况（`W新 = W旧 - 学习率 * 梯度`）

#### Smooth L1

- 基于上面两种函数做的综合
- 在 `{-1, 1}` 区间是 MSE，其他分段是 MAE
- ✅ 既解决了 L1 的 0 点不可导问题，也解决了 MSE 的梯度爆炸问题
- 多数情况下使用 Smooth L1

## 5. 模型训练的三个概念

| 概念 | 说明 |
|------|------|
| **Epochs** | 使用全部数据对模型进行完整的训练次数 |
| **Batch** | 使用训练集中的小部分样本对模型权重进行反向传播的参数更新，每次训练每批次样本的数量 |
| **Iteration** | 使用一个 batch 数据对模型进行一次参数更新的过程，每次训练批次数 |

> batch 计算方式：`batch = epochs / batch_size + 1`

---

## 6. 反向传播更新梯度时遇到的问题

- **平缓区域**：梯度值较小，参数优化变慢
- **鞍点**：梯度为 0，参数无法优化
- **局部最小值**：参数不是最优

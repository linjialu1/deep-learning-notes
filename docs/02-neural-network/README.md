## 1. 神经网络概念

### 1.1 什么是神经网络

人工神经网络（Artificial Neural Network，简称 ANN）是一种模仿生物神经网络结构和功能的**计算模型**。它由多个互相连接的人工神经元构成，可以用于处理和学习复杂的数据模式，尤其适合解决非线性问题。

### 1.2 神经网络的层结构

神经网络由三种层组成：

- **输入层（Input Layer）**：输入数据的那一层（如图像、文本、声音等）。每个输入特征对应一个神经元
- **输出层（Output Layer）**：输出预测结果的那一层，根据任务（回归、分类等）生成最终结果
- **隐藏层（Hidden Layers）**：输入层和输出层之间的都是隐藏层，网络的"深度"通常由隐藏层的数量决定

### 1.3 全连接神经网络的特点

- 同一层的神经元之间没有连接
- 第 N 层的每个神经元和第 N-1 层的所有神经元相连（这就是 Fully Connected 的含义）
- 第 N-1 层神经元的输出就是第 N 层神经元的输入
- 每个连接都有一个权重值（w 系数和 b 系数）

### 1.4 神经元的内部状态值和激活值

每一个神经元工作时，**前向传播**会产生两个值：

- **内部状态值（加权求和值）**：`z = w·x + b`
  - w：权重矩阵
  - x：输入值
  - b：偏置
- **激活值**：通过激活函数对内部状态值进行非线性变换后的结果，`a = f(z)`
  - f：激活函数
  - z：内部状态值

## 2. 激活函数（Activation Function）

### 2.1 为什么需要激活函数

> 没有引入非线性因素的网络等价于使用一个线性模型来拟合。通过给网络输出增加激活函数，实现引入非线性因素，使得网络模型可以逼近任意函数，提升网络对复杂问题的拟合能力。

激活函数用于对每层的**输出数据进行变换**，进而为整个网络注入**非线性因素**。如果不使用激活函数，整个网络虽然看起来复杂，其本质还相当于一种线性模型。

> 注意：激活函数必须可微，因为网络参数更新使用反向传播算法（BP）。

### 2.2 Sigmoid

- 将任意输入映射到 **(0, 1)** 之间
- 当输入值大致在 `<-6` 或 `>6` 时，输出趋近饱和，丢失部分信息
- **导数数值范围是 (0, 0.25)**，输入过大或过小时导数接近为 0
- 网络 5 层之内容易出现**梯度消失**现象
- 激活值不是以 0 为中心的，总是偏向正数
- 一般用于**二分类的输出层**

### 2.3 Tanh

- 将输入映射到 **(-1, 1)** 之间
- 图像以 0 为中心，在 0 点对称
- 当输入大概 `<-3` 或 `>3` 时，将被映射为 -1 或 1
- **导数值范围 (0, 1)**，输入过大或过小时导数近似 0

**与 Sigmoid 对比：**
- 优点：以 0 为中心，梯度比 Sigmoid 大，收敛速度更快，迭代次数更少
- 缺点：两侧导数同样为 0，依然会造成梯度消失
- 提示：隐藏层可使用 tanh，输出层使用 sigmoid

### 2.4 ReLU

- 将小于 0 的值映射为 0，大于 0 的值保持不变
- 更重视正信号，忽略负信号
- 运算简单，提高模型训练效率
- **目前最常用的激活函数**

**ReLU 的优势：**
- 计算量小（不像 sigmoid 需要指数运算）
- 当输入值 > 0 时，梯度为 1，不会出现梯度消失
- 会使一部分神经元的输出为 0，造成网络稀疏性，缓解过拟合

**神经元死亡问题：**
- 当 `x < 0` 时，ReLU 的导数 = 0
- 训练推进过程中，部分输入会落入小于 0 的区域，对应的权重无法更新，导致"神经元死亡"

**改进版本：PReLU（Leaky ReLU）**
- 可以接受负的信号，用来解决神经元死亡问题

### 2.5 Softmax

- 用于**多分类**过程
- 是二分类函数 Sigmoid 在多分类上的推广
- 目的是将多分类结果以**概率**形式展现
- 将网络输出的 logits 通过 softmax 函数，映射成为 (0,1) 的值，这些值的累和为 1（满足概率的性质）
- 输出结果选取多分类中概率最大的那个

### 2.6 如何选择激活函数

**对于隐藏层：**
1. 优先选择 ReLU 激活函数
2. 如果 ReLU 效果不好，尝试其他激活，如 Leaky ReLU 等
3. 使用 ReLU 时注意 Dead ReLU 问题，避免过多神经元死亡
4. 少使用 sigmoid，可以尝试使用 tanh

**对于输出层：**
1. 二分类问题 → sigmoid
2. 多分类问题 → softmax
3. 回归问题 → identity（线性）

## 3. 参数初始化

### 3.1 初始化的目的

> 偏置一般初始化为 0 即可，权重初始化更加重要。

1. **打破对称性**：权重的初始化需要打破对称性，否则网络的学习能力会受到限制
2. **防止梯度消失或爆炸**：初始权重值过大或过小会导致梯度在反向传播中指数级增大或缩小
3. **提高收敛速度**：合理的初始化使得网络的激活值分布适中，有助于梯度高效更新

### 3.2 常见初始化方法（7 种）

#### 随机初始化

- **均匀分布初始化**：从区间均匀随机取值，默认区间为 (0, 1)
- **正态分布初始化**：从均值为 0，标准差是 1 的高斯分布中取样
- 优点：能有效打破对称性
- 缺点：随机选择范围不当可能导致梯度问题
- 适用场景：浅层网络或低复杂度模型（隐藏层 1-3 层，总层数不超过 5 层）

#### 全 0 初始化

- 将所有权重参数初始化为 0
- 优点：实现简单
- 缺点：无法打破对称性，所有神经元更新方向相同，无法有效训练
- 适用场景：几乎不使用，仅用于偏置项的初始化

#### 全 1 初始化

- 将所有权重参数初始化为 1
- 缺点：
  - 无法打破对称性，所有神经元更新方向相同
  - 会导致激活值在网络中呈指数增长，容易出现梯度爆炸
- 适用场景：测试或调试，验证网络是否能正常前向传播和反向传播

#### 固定值初始化

- 将所有权重参数初始化为某个固定值
- 缺点：
  - 无法打破对称性
  - 初始权重过大或过小可能导致梯度爆炸或梯度消失
- 适用场景：测试或调试

#### Kaiming 初始化（HE 初始化）

- **专为 ReLU 和其变体设计**，考虑到 ReLU 激活函数的特性，对输入维度进行缩放
- 分为正态分布和均匀分布两种
  - 正态分布：`std = sqrt(2 / fan_in)`
  - 均匀分布：`limit = sqrt(6 / fan_in)`
- `fan_in`：当前层接受的来自上一层的神经元数量
- 优点：适合 ReLU，能保持梯度稳定
- 缺点：对非 ReLU 激活函数效果一般
- 适用场景：深度网络（10 层及以上），使用 ReLU、Leaky ReLU 激活函数

#### Xavier 初始化（Glorot 初始化）

- 根据网络输入和输出的维度自动选择权重范围，使输入和输出的方差相同
- 分为正态分布和均匀分布两种
  - 正态分布：`std = sqrt(2 / (fan_in + fan_out))`
  - 均匀分布：`limit = sqrt(6 / (fan_in + fan_out))`
- `fan_in`：当前层接收的输入神经元数量
- `fan_out`：当前层输出的神经元数量
- 优点：适用于 Sigmoid、Tanh 等激活函数，解决梯度消失问题
- 缺点：对 ReLU 等激活函数表现欠佳
- 适用场景：深度网络（10 层及以上），使用 Sigmoid 或 Tanh 激活函数

### 3.3 如何选择初始化方法

- **根据激活函数选择**：
  - Sigmoid / Tanh → Xavier 初始化
  - ReLU / Leaky ReLU → Kaiming 初始化
- **根据网络深度选择**：
  - 浅层网络 → 随机初始化即可
  - 深层网络 → 需要考虑方差平衡，如 Xavier 或 Kaiming

> 提示：激活函数使用最多的是 ReLU，Kaiming 初始化专门针对 ReLU 函数做了优化设计。

## 4. 神经网络的搭建

### 4.1 搭建步骤

神经网络的搭建分为 3 步：

1. 定义一个类，继承 `nn.Module`
2. 在 `__init__()` 方法中，搭建神经网络（定义层结构）
3. 在 `forward()` 方法中，完成前向传播（数据经过各层的计算）

### 4.2 模型参数计算

以一个简单网络为例：
- 第 1 个隐藏层：3 个输入特征，3 个神经元 → 3×4 = 12 个参数（每个神经元有 3 个权重 + 1 个偏置）
- 第 2 个隐藏层：3 个输入特征，2 个神经元 → 3×2 + 2 = 8 个参数
- 输出层：2 个输入特征，2 个神经元 → 2×2 + 2 = 6 个参数

> 注意：输入数据和网络权重是两个不同的事儿，要分得清。

### 4.3 数据形状变化

- 输入：5 行数据，3 个特征 → `[5, 3]`
- 经过各层后，输出形状由最后一层的神经元个数决定
- 输入有多少行，输出就有多少行（每行对应一个样本的预测结果）

## 5. 损失函数

> 在深度学习中，损失函数是用来**衡量模型参数质量的函数**，衡量方式是比较网络输出（预测值）和真实输出（真实值）的差异。模型通过最小化损失函数的值来调整参数，使其输出更接近真实值。

**损失函数的作用：**
- **评估性能**：反映模型预测结果与目标值的匹配程度
- **指导优化**：通过梯度下降等算法最小化损失函数，优化模型参数

### 5.1 多分类任务损失函数

在多分类任务通常使用 softmax 将 logits 转换为概率的形式，所以多分类的交叉熵损失也叫做 **softmax 损失**。

大白话：最小化正确类别所对应的预测概率的对数负数。

公式：`L = -∑ y log(S(f(x)))`

- `y_i` 是样本 x 属于某一个类别的真实概率
- `f(x)` 是样本属于某一类别的预测分数
- `S` 是 softmax 激活函数
- `L` 用来衡量真实值 y 和预测值 f(x) 之间差异性的损失结果

> PyTorch 中使用 `nn.CrossEntropyLoss()` 实现（内部已包含 softmax）

### 5.2 二分类任务损失函数

二分类任务使用 sigmoid 激活函数，对应的损失函数为二分类交叉熵损失。

公式：`L = -y log(x) - (1-y) log(x)`

- `y` 为真实值
- `x` 为样本的预测概率
- `L` 用来衡量真实值 y 与预测值 x 之间的损失结果

> PyTorch 中使用 `nn.BCELoss()` 实现（需要手动调用 sigmoid）

### 5.3 回归任务损失函数

#### MAE 损失函数（L1 Loss）

- 公式：误差绝对值之和 / 样本总数
- 适用场景：回归问题中存在异常值或噪声数据时，减少对离群点的敏感性
- 缺点：在 0 点不可导，梯度不平滑，会跳过极小值，数据容易变得稀疏
- 由于 L1 loss 具有稀疏性，常常作为正则项添加到其他 loss 中作为约束

> PyTorch 中使用 `nn.L1Loss()` 实现

#### MSE 损失函数（L2 Loss）

- 公式：误差平方值和 / 样本总数
- 适用场景：大多数标准回归问题，如房价预测、温度预测等
- 缺点：
  - 对于离群点敏感，因为平方项会放大大误差
  - 如果差值过大，可能存在梯度爆炸的情况（`W新 = W旧 - 学习率 * 梯度`）
- 也常常作为正则项

> PyTorch 中使用 `nn.MSELoss()` 实现

#### Smooth L1

- 基于上面两种函数做的综合，结合了 MSE 和 MAE 的优点
- 在 `[-1, 1]` 区间是 MSE，其他分段是 MAE
- 优点：既解决了 L1 的 0 点不可导问题，也解决了 MSE 的梯度爆炸问题
- 优点：对离群点更加鲁棒，计算梯度时更加平滑
- 多数情况下使用 Smooth L1

> PyTorch 中使用 `nn.SmoothL1Loss()` 实现

## 6. 模型训练的三个概念

| 概念 | 说明 |
|------|------|
| **Epoch** | 使用全部数据对模型进行一次完整的训练次数 |
| **Batch** | 使用训练集中的小部分样本对模型权重进行反向传播的参数更新，每次训练每批次样本的数量 |
| **Iteration** | 使用一个 batch 数据对模型进行一次参数更新的过程，每次训练批次数 |

> 举例：50000 个训练样本，Batch Size = 256
> - 每个 Epoch 的 Batch 个数：50000 / 256 + 1 ≈ 196
> - 10 个 Epoch 的 Iteration 个数：196 × 10 = 1960

## 7. 反向传播（BP 算法）

### 7.1 前向传播与反向传播

- **前向传播**：数据从输入层到输出层逐层向前传递，计算网络的输出值（预测值）
- **反向传播（Back Propagation）**：利用损失函数 ERROR 值，从后往前，结合梯度下降算法，依次求各个参数的偏导，并进行参数更新

### 7.2 反向传播原理

反向传播算法利用**链式法则**对神经网络中的各个节点的权重进行更新。

> 梯度的方向是函数增长速度最快的方向，那么梯度的反方向就是函数减少最快的方向。
> 参数更新公式：`W新 = W旧 - 学习率 * 梯度`

### 7.3 更新梯度时遇到的问题

- **平缓区域**：梯度值较小，参数优化变慢
- **鞍点**：梯度为 0，参数无法优化
- **局部最小值**：参数不是最优

## 8. 梯度下降的优化方法

### 8.1 指数加权平均

我们常见的算术平均指的是将所有数加起来除以数的个数，每个数的权重相同。

**指数移动加权平均**则是参考各数值，并且各数值的权重都不同：距离越远的数字对平均数计算的贡献就越小（权重较小），距离越近则对平均数的计算贡献就越大（权重越大）。

计算公式：

`S_t = β * S_{t-1} + (1 - β) * Y_t`

- `S_t` 表示指数加权平均值
- `Y_t` 表示 t 时刻的值
- `β` 调节权重系数，该值越大平均数越平缓

**特点：**
- 指数加权平均绘制出的曲线更加平缓
- β 的值越大，则折线越加平缓，波动越小
- β 值一般默认都是 0.9

### 8.2 Momentum（动量算法）

当梯度下降碰到"峡谷"、"平缓"、"鞍点"区域时，参数更新速度变慢。Momentum 通过**指数加权平均法**，累计历史梯度值，进行参数更新，越近的梯度值对当前参数更新的重要性越大。

**梯度计算公式：**
`s_t = β * s_{t-1} + (1 - β) * g_t`

**参数更新公式：**
`w_t = w_{t-1} - η * s_t`

- `s_t` 是当前时刻指数加权平均梯度值
- `s_{t-1}` 是历史指数加权平均梯度值
- `g_t` 是当前时刻的梯度值
- `β` 是调节权重系数，通常取 0.9 或 0.99
- `η` 是学习率

**Momentum 如何克服问题：**
- **鞍点**：当前梯度为 0，但先前积累的梯度值很有可能使得跨过鞍点
- **震荡**：普通梯度下降每次选取少数样本梯度确定前进方向，可能出现震荡；Momentum 使用移动加权平均，平滑了梯度的变化，使得前进方向更加平缓

### 8.3 AdaGrad

AdaGrad 通过对不同的参数分量使用不同的学习率。**AdaGrad 的学习率总体会逐渐减小**：起初距离最优目标较远，可以使用较大的学习率加快训练，随着迭代次数增加，学习率逐渐下降。

**计算步骤：**
1. 初始化学习率 η、参数 w、小常数 σ = 1e-10
2. 初始化梯度累计变量 s = 0
3. 采样小批量，计算梯度 `g_t`
4. 累积平方梯度：`s_t = s_{t-1} + g_t ⊙ g_t`
5. 学习率调整：`η = η / (√s_t + σ)`
6. 更新权重：`w_t = w_{t-1} - (η / (√s_t + σ)) * g_t`

- 缺点：可能会使得学习率过早、过量地降低，导致模型训练后期学习率太小，较难找到最优解

### 8.4 RMSProp

**RMSProp 优化算法是对 AdaGrad 的优化**。最主要的不同是，其使用**指数加权平均梯度**替换历史梯度的平方和。

**与 AdaGrad 的区别：**
- 使用指数加权平均累计历史梯度：`s_t = β * s_{t-1} + (1-β) * g_t ⊙ g_t`
- 通过引入衰减系数 β，控制历史梯度对历史梯度信息获取的多少
- 被证明在神经网络非凸条件下的优化更好，学习率衰减更加合理

> 提示：AdaGrad 和 RMSProp 都是对于不同的参数分量使用不同的学习率：梯度值较大的参数分量，对应的学习率就较小；梯度较小的参数分量，对应的学习率就较大。

### 8.5 Adam

Adam 优化算法（Adaptive Moment Estimation，自适应矩估计）将 **Momentum** 和 **RMSProp** 算法结合在一起：
- **修正梯度**：使用梯度的指数加权平均（一阶矩）
- **修正学习率**：使用梯度平方的指数加权平均（二阶矩）

**原理**：计算了梯度的一阶矩（平均值）和二阶矩（梯度的方差）的自适应估计，从而动态调整学习率。

**梯度计算公式：**
- `m_t = β_1 * m_{t-1} + (1 - β_1) * g_t`（一阶矩）
- `s_t = β_2 * s_{t-1} + (1 - β_2) * g_t²`（二阶矩）
- 偏差校正：`m̂_t = m_t / (1 - β_1^t)`，`ŝ_t = s_t / (1 - β_2^t)`

**参数更新公式：**
`w_t = w_{t-1} - (η / (√ŝ_t + ε)) * m̂_t`

### 8.6 优化算法对比小结

| 优化算法 | 优点 | 缺点 | 适用场景 |
|---------|------|------|---------|
| **SGD** | 简单、容易实现 | 收敛速度较慢，容易震荡 | 简单任务，数据特征分布相对稳定 |
| **Momentum** | 加速收敛，减少震荡 | 需要手动调整动量超参数 | 非平稳优化问题，深度学习应用 |
| **AdaGrad** | 自适应调整学习率，适用于稀疏数据 | 学习率逐渐衰减，可能导致早期停滞 | 稀疏数据，如 NLP 或推荐系统 |
| **RMSProp** | 解决了 AdaGrad 学习率过早衰减的问题 | 需要选择合适的超参数 | 动态问题、非平稳目标函数 |
| **Adam** | 结合 Momentum 和 RMSProp 的优点，适应性强且稳定 | 需要调节更多超参数 | 广泛适用于各种深度学习任务 |

**选择建议：**
- 简单任务和较小的模型 → SGD 或 Momentum
- 复杂任务或有大量数据 → Adam 是最常用的选择
- 需要处理稀疏数据或文本数据 → Adagrad 或 RMSProp

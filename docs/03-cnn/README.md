# 卷积神经网络（CNN）笔记

## 1. 图像基础知识

### 1.1 图像的类型

| 图像类型 | 通道数 | 像素值范围 | 说明 |
|---------|-------|-----------|------|
| 二值图像 | 1 | 0 或 1 | 只有黑白两种值，用于 OCR、掩膜 |
| 灰度图像 | 1 | 0 ~ 255 | 每个像素表示亮度，0 黑 255 白 |
| RGB 图像 | 3 | 0 ~ 255 | 每个像素由 R、G、B 三个通道组成 |

> 深度学习中常用的是 RGB 彩色图像，形状为 (H, W, C)，即高、宽、通道数。

### 1.2 图像的基本概念

- 图像由像素点组成，每个像素点的取值范围为 [0, 255]
- 像素值越接近 0，颜色越暗（接近黑色）
- 像素值越接近 255，颜色越亮（接近白色）

## 2. 卷积神经网络概述

### 2.1 什么是卷积神经网络

卷积神经网络（Convolutional Neural Network）是含有卷积层的神经网络，专门用于处理图像、视频等具有网格结构的数据。

**CNN 的优势：**
- 避免了全连接网络参数过多的问题
- 能够自动提取图像的局部特征
- 具有平移不变性，物体在图像中任意位置都能被识别

### 2.2 CNN 的基本结构

CNN 主要由三部分构成：

1. **卷积层（Conv）**：提取图像中的局部特征（边缘、纹理、形状等）
2. **池化层（Pool）**：降低特征图尺寸，减少计算量，提高鲁棒性
3. **全连接层（FC）**：将提取的特征组合起来，输出最终分类结果

典型的卷积神经网络结构：
```
输入图像 → 卷积层 → 激活函数 → 池化层 → 卷积层 → 激活函数 → 池化层 → 全连接层 → 输出
```

### 2.3 典型应用

- **图像分类**：识别图片中的物体类别（如猫狗分类）
- **目标检测**：检测图像中物体的位置和类别

### 2.4 经典网络架构

| 网络 | 特点 |
|------|------|
| LeNet-5 | 最早的 CNN 架构，用于手写数字识别 |
| AlexNet | 首次证明深度学习在图像分类上的优势，使用 ReLU 和 Dropout |
| VGGNet | 使用多个 3x3 小卷积核堆叠，证明网络越深效果越好 |
| ResNet | 引入残差块和跳跃连接，解决了深度网络梯度消失问题 |

## 3. 卷积层

### 3.1 卷积的基本原理

卷积运算本质上是卷积核（滤波器）和输入数据的局部区域做点积。

**核心概念：**
- **卷积核（Filter）**：一组固定权重的矩阵，一个卷积核就是一个神经元
- **特征图（Feature Map）**：输入图像经过卷积核处理后得到的输出

**卷积层的特点：**
- **局部连接**：每个神经元只和输入图像的一个小局部区域相连
- **权重共享**：同一个卷积核在整个图像上滑动，参数数量大大减少
- **平移不变性**：不论物体出现在图像哪个位置，都能被检测到

### 3.2 Padding（填充）

在输入特征图的边界周围添加额外的像素（通常是 0）。

**作用：**
- 保持输出特征图的尺寸和输入相同
- 保留图像边缘的信息（边缘像素在卷积中参与计算次数少）

**常见类型：**
- **Valid Padding**：不填充，输出尺寸会缩小
- **Same Padding**：填充后输出尺寸和输入相同

### 3.3 Stride（步长）

卷积核在图像上滑动时的步伐大小。

**作用：**
- 步长越大，输出特征图尺寸越小
- 可以替代池化层实现降维
- 增大感受野，每个神经元能看到更大范围的输入

### 3.4 多通道卷积

- 输入有多个通道（如 RGB 三个通道）时，卷积核也需要有相同的通道数
- 每个卷积核通道和对应的输入通道分别做卷积
- 每个通道的卷积结果按位相加，得到最终的特征图

### 3.5 多卷积核卷积

使用多个不同的卷积核，可以从不同角度提取图像的不同特征。

- 有多少个卷积核，输出就有多少个通道
- 每个卷积核提取一种特征（如边缘、纹理、颜色等）

### 3.6 特征图大小计算

输出特征图尺寸的计算公式：

```
输出尺寸 = (输入尺寸 - 卷积核大小 + 2 × 填充) / 步长 + 1
```

> 如果除不尽，向下取整。

### 3.7 PyTorch 卷积层 API

```python
nn.Conv2d(in_channels, out_channels, kernel_size, stride=1, padding=0)
```

**参数说明：**
- `in_channels`：输入通道数，RGB 图片一般是 3
- `out_channels`：输出通道数，也就是卷积核的数量
- `kernel_size`：卷积核的高和宽，一般为 3、5、7（通常用奇数）
- `stride`：步长，默认 1
  - 整数：所有维度使用相同步长
  - 元组：不同维度设置不同步长
- `padding`：填充数量，默认 0
  - `padding=1`：四周各填充 1 个像素
  - `padding='same'`：输出尺寸和输入保持一致（stride 必须为 1）

## 4. 池化层

### 4.1 池化的作用

池化层用于降低特征图的空间维度，减少计算量。

**作用：**
- **降维减参**：减少特征图尺寸，降低计算量和内存消耗
- **提高鲁棒性**：特征对小的平移、旋转不敏感
- **防止过拟合**：减少模型复杂度
- **抽象特征**：提取更高层次的抽象特征

### 4.2 常见池化方式

- **最大池化（Max Pooling）**：取池化窗口中的最大值作为输出
- **平均池化（Avg Pooling）**：取池化窗口内所有值的均值作为输出

> 最大池化比平均池化更常用，因为它能更好地保留显著特征。

### 4.3 多通道池化

- 池化层对每个输入通道分别进行池化
- 池化前后通道数不变
- 池化只在宽和高维度上操作，通道数不改变

### 4.4 PyTorch 池化层 API

```python
# 最大池化
nn.MaxPool2d(kernel_size=2, stride=2, padding=0)

# 平均池化
nn.AvgPool2d(kernel_size=2, stride=2, padding=0)
```

**参数说明：**
- `kernel_size`：池化核的大小
- `stride`：步长，通常和 kernel_size 相同（如 2x2 池化，步长 2）
- `padding`：填充数量

## 5. 图像分类实战（CIFAR10）

### 5.1 CIFAR10 数据集

- 5 万张训练图像，1 万张测试图像
- 10 个类别（飞机、汽车、鸟、猫、鹿、狗、青蛙、马、船、卡车）
- 图像大小 32×32×3

### 5.2 典型网络结构

一个简单的 CNN 分类网络结构：

```
输入: 3×32×32
  ↓
Conv1: 3→6 通道, 3×3 卷积
  ↓
ReLU + MaxPool: 6×15×15
  ↓
Conv2: 6→16 通道, 3×3 卷积
  ↓
ReLU + MaxPool: 16×6×6
  ↓
展平: 16×6×6 = 576 维
  ↓
Linear1: 576→120
  ↓
Linear2: 120→84
  ↓
输出: 84→10（10 个类别）
```

### 5.3 训练流程

1. 加载数据集（CIFAR10）
2. 构建 CNN 模型
3. 选择损失函数（交叉熵）和优化器（Adam）
4. 训练循环：前向传播 → 计算损失 → 反向传播 → 更新参数
5. 保存模型

### 5.4 模型优化

过拟合时的优化方法：
- 增加 Dropout 层
- 增加网络深度和通道数
- 调整学习率
- 使用 Batch Normalization
